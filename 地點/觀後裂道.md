# 觀後裂道

> [!info] 一句話
> 自[清鑑觀地窖](../地點/清鑑觀地窖.md)天頂裂縫通往觀後山壁的舊裂道,俗稱「骨灰路」。石壁刮痕以骨頭而非鑿子所刻、沿途鋪[骨灰](../設定/骨灰.md)。三年前[麻衣人](../人物/麻衣人.md)來去之路;盡頭是斷崖石棚。

## 概述
- **所在**：[清鑑觀地窖](../地點/清鑑觀地窖.md)天頂裂縫 → 觀後山壁斷崖
- **類型**：舊裂道／逃生口（亦是「口子」）
- **重要性**：一行逃離地窖之路;牽出[老秦](../人物/老秦.md)、[麻衣人](../人物/麻衣人.md)身分之謎。

## 描述
- 極窄,最窄處僅容一人貼壁;傾斜漸陡。
- 石壁青色紋路被刮去大半、只剩起收筆;刮痕係「用骨頭」刻成(見[第二十章](../chapters/ch20_agy.md))。
- 沿途[骨灰](../設定/骨灰.md)與[識文短香](../設定/識文短香.md)氣味交雜。
- 盡頭斷崖中段有不足兩尺寬石棚,苔下壓一隻磨薄草鞋,鞋底刻歪斜「秦」字。

- **[第二十章](../chapters/ch20_agy.md)**：三人穿裂道;識文辨骨灰;石棚見刻「秦」字草鞋;松林現[松林身影](../人物/松林身影.md)。
