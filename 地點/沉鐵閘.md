# 沉鐵閘

> [!info] 一句話
> 位於[漕渠](../地點/漕渠.md)舊道塌斷處下方的一道生鐵水門,門軸鏽死大半。門後石壁有不同於[回聲井](../地點/回聲井.md)輿圖的[太一刻紋](../設定/太一遺構.md),[韓藥塵](../人物/韓藥塵.md)形容其「更像一道問題」,內容未明。

## 概述
- **所在**：[漕渠](../地點/漕渠.md)塌斷處下方
- **類型**：生鐵水門／[太一遺構](../設定/太一遺構.md)
- **重要性**：促成一行前往[清鑑觀](../地點/清鑑觀.md)尋[識文](../人物/識文.md)解讀的關鍵謎題。

## 描述
- 生鐵水門,門軸鏽死大半,仍擋著門後之物。
- 門後石壁刻紋與回聲井「輿圖(路)」不同,「更像一道問題」。
- 韓藥塵三月前重勘渡風口方圓二十里暗路時標於帛書水道圖(墨色極新)。
- 韓藥塵上次靠近時,小臂[舊疤](../設定/韓藥塵舊疤.md)自行裂開。
