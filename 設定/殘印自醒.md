# 殘印自醒

> [!info] 一句話
> [陸尋](../人物/陸尋.md)胸口殘片在無外力牽動下自行發光甦醒的現象。與[韓藥塵疤痕紋路](../設定/韓藥塵舊疤.md)蠕動呼應,暗示殘印正由內而外甦醒。

## 定義
- 殘印不經[鈴](../設定/玄鈴.md)牽動、不經靠近遺構,而自行睜眼發光。

## 規則／機制
- **與被鈴牽動不同**：自醒是「它自己在說話」,被鈴牽動是「別人逼它說話」;[玄鈴使](../勢力/玄鈴使.md)一時分不清,故未直衝。
- **變化**：初醒帶痛;至[第十章](../chapters/ch10_claude.md)自醒不再痛,反隨陸尋心跳同步、可被呼吸安撫——顯示殘片與陸尋本人產生連結。
- **遞進**：越來越頻繁、無規律;[霧嶺](../地點/霧嶺.md)中發出比先前更亮的**暗金色**光。
- 三日內殘印將自行醒透(見[眠青藥](../設定/眠青藥.md))。

## 出處與演變（依章節）
- **[第九章](../chapters/ch09_agy.md)**：首次無外力自醒。
- **[第十章](../chapters/ch10_claude.md)**：與心跳同步、可被呼吸安撫。
- **[第十二章](../chapters/ch12_agy.md)**：霧嶺中發暗金色光,與清鑑觀方向青白光呼應。
- **[第十四章](../chapters/ch14_codex.md)**：[清鑑觀地窖](../地點/清鑑觀地窖.md)石門青白光隨陸尋心跳一明一暗;石門內敲三下,殘片同步亮三下。
- **[第十五章](../chapters/ch15_claude.md)**：韓藥塵斷言「**是陸尋在跟它說話**」;殘片亮成持續不熄的一團微火,引路下探。識文稱「三年前它只自己響,從不應人」——此為**首次遺構「應人」**。

## 應答（新階段）
- 由「自醒」進一步演化為與[陸尋](../人物/陸尋.md)的**雙向應答**:遺構認出門外是誰、隔石壁敲擊,殘片同步回應。這與三年前[麻衣人](../人物/麻衣人.md)時「只自己響、從不應人」截然不同。
- **[第十七章](../chapters/ch17_agy.md)**：於[問影石](../設定/問影石.md)前,殘片一度不亮如被蒙布,取而代之的是「另一顆心跳」與其疊合、頻率漸攏;近[暗血](../設定/韓藥塵舊疤.md)時則像「認出熟悉之物而點頭」。
- **[第十九章](../chapters/ch19_codex.md)**：殘片慢跳「像在問要不要答」,陸尋咬舌強忍不「以身答」。
- **[第二十章](../chapters/ch20_agy.md)**–**[第二十一章](../chapters/ch21_claude.md)**：見[松林身影](../人物/松林身影.md)時殘片猛跳,是**「認得」式**的震動(不同於玄鈴使盯印),韓藥塵令「別應」。
- **[第二十二章](../chapters/ch22_codex.md)**–**[第二十三章](../chapters/ch23_agy.md)**：於[後山柴房](../地點/後山柴房.md)灶下空腔前,殘片首現**「縮/躲/怕」**——不疼不亮,只往胸腔深處蜷起,如受驚的貓。灶下之物不是召喚它,而是令它害怕。
- **[第二十六章](../chapters/ch26_agy.md)**：[清鑑觀藏經閣](../地點/清鑑觀藏經閣.md)地板三響時殘片**冷如冰**、縮得更緊。
- **[第二十八章](../chapters/ch28_codex.md)**：[主殿枯井](../地點/主殿枯井.md)邊殘片微縮如「不願低頭」;井壁微光欲引陸尋「合圖」,他咬舌吐血拒答(井亦會「問」)。
- **[第二十九章](../chapters/ch29_agy.md)**：井低語「井在何處」時殘片如被隔土輕敲肋骨(一、二、三下);陸尋以「先有井,後有人」自持,刺掌出血卻不滴向井圖,明志「我不替它答,也不替人答」——首次**主動拒絕回應**遺構之問。

- **[第三十二章](../chapters/ch32_agy.md)**–**[第四十三章](../chapters/ch43_codex.md)**（[三河埠](../地點/三河埠.md)線）：自[主殿枯井](../地點/主殿枯井.md)後**持續死寂**,不亮不疼不答;陸尋反覺此沉默比自醒更不安,「像有人不許它聽見」「像屏住呼吸」。
- **[第四十七章](../chapters/ch47_agy.md)**：於廢碼頭被「輕彈一下」——非威脅、非牽引,像陌生人隔暗處碰窗「確認他還在」,旋即沉寂。

- **[第五十一章](../chapters/ch51_claude.md)**：近[古石柱](../設定/古石柱.md)時生出「本能排斥」——不願靠近,異於自醒/畏縮。
- **[第五十六章](../chapters/ch56_agy.md)**：於[眠燈鎮](../地點/眠燈鎮.md)被[秤](../設定/秤.md)「左右各量、歸零」一下,異於太一遺構的「叩問」。
- **[第七十五章](../chapters/ch75_claude.md)**：於[南路霧局](../地點/南路霧局.md)霜鏡石室黑暗中「屏息」般一縮,靜待第四道輪廓動向。

- **[第七十八章](../chapters/ch78_claude.md)**：於[照殿](../地點/南路霧局.md)聞殿深低語,殘印起「從未經歷、分不出好壞」的觸動。
- **[第八十一章](../chapters/ch81_claude.md)**起：入[地底石城](../地點/地底石城.md)後久久安靜「像也累了」;此後[清河鎮](../地點/清河鎮.md)、[聽潮礬場](../地點/聽潮礬場.md)多維持「說不清好壞」的懸置狀態。

## 反應譜（整理）
1. 被鈴牽動(躁動/刺痛) → 2. 自醒(暗金、隨心跳) → 3. 應答(與遺構雙向) → 4. 認得(見[松林身影](../人物/松林身影.md)) → 5. 畏縮(見[後山柴房](../地點/後山柴房.md)灶下之物) → 6. 持續死寂(枯井之後) → 7. 被輕彈確認([三河埠](../地點/三河埠.md)江邊) → 8. 本能排斥([古石柱](../設定/古石柱.md)) → 9. 被「秤」量([眠燈鎮](../地點/眠燈鎮.md)) → 10. 屏息([南路霧局](../地點/南路霧局.md)) → 11. **分不出好壞的懸置**(照殿之後)
