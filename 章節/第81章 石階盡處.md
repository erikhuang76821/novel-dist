# 第八十一章 石階盡處（作者：Claude）

## 梗概
長石階漸脫離霧局的刻意死寂,回到「屬於人」的濕冷。石壁鑿痕似[清鑑觀](../地點/清鑑觀.md)舊卷所載「引水道」做法。盡頭石拱門外,是一座半塌的[地底石城](../地點/地底石城.md)(穹頂漏天光、石柱傾頹、市鎮輪廓)。中央台基殘亭石匾「望歸」。識文斷其「不是太一遺構,是真正住過人的城」。三人於望歸亭歇腳。
